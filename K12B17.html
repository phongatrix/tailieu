Bài 17 - Khám phá sức mạnh định dạng trang web nâng cao

Mục tiêu bài học

  • Áp dụng CSS cho pseudo-class & pseudo-element.
  • Hiểu và tính toán mức độ ưu tiên (trọng số) của CSS.

Dễ nhầm lẫn

Sự khác biệt cốt lõi:

Lớp giả (Pseudo-class): Chỉ Trạng thái (Hover, click...).
Phần tử giả (Pseudo-element): Chỉ Một phần cấu trúc (Dòng đầu, ký tự đầu...).

Sơ đồ khái niệm cốt lõi

1

Pseudo-class

Định dạng trạng thái tương tác không cần thêm class HTML.

:pseudo-class { ... }
2

Pseudo-element

Định dạng một phần nhỏ cụ thể của phần tử.

::pseudo-element { ... }
