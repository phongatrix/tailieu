Thẻ HTML Trọng Tâm

  • <div> Dùng để tạo khối, dựng khung cho các thành phần (Banner, Slogan).
  • <h2>,<h3> Chứa tiêu đề trang hoặc tiêu đề các khối nội dung.
  • <p> Đoạn văn bản chứa nội dung chi tiết.

Định Dạng CSS (style.css)

  • .class Sử dụng chọn lớp (ví dụ: .banner, .slogan) để định dạng chung.
  • flex Thuộc tính display: flex quan trọng để xếp các ô nằm ngang.
  • :hover Hiệu ứng di chuột (bài tập vận dụng).

Mã HTML Khung

Mô phỏng cấu trúc HTML và CSS dựa trên Sơ đồ bố cục. Khung mã này đã bao gồm định dạng chia cột cơ bản.

<!-- 1. MÃ HTML -->
<div class="header">
  <div class="banner">
    <h2>TÊN CÂU LẠC BỘ</h2>
  </div>
  <div class="slogan">
    <div class="row">
      <div class="block_3">Năng động</div>
      <div class="block_3">Đam mê</div>
      <div class="block_3">Toả sáng</div>
    </div>
  </div>
</div>

<div class="content">
  <!-- Khung 4 Ảnh/Nội dung -->
  <div class="row">
    <div class="box_content">Ảnh/Nội dung 1</div>
    <div class="box_content">Ảnh/Nội dung 2</div>
    <div class="box_content">Ảnh/Nội dung 3</div>
    <div class="box_content">Ảnh/Nội dung 4</div>
  </div>
</div>

<div class="footer">
  <p>Bản quyền © 2026 - Trường THPT Trương Định - HF</p>
</div>

/* 2. MÃ CSS (style.css) */
.row {
  display: flex;
  flex-wrap: wrap;
}
.block_3 {
  width: 33.33%; /* Chia 3 cột */
}
.box_content {
  width: 50%; /* Chia 2 cột */
  padding: 10px;
}
.banner {
  background-image: url("../assets/img/bg.jpg");
  text-align: center;
}
.footer {
  background-color: #334155;
  color: white;
  text-align: center;
}

Mô Phỏng Thuộc Tính Flex

Nhấn nút bên trên để xem cách lớp .row điều khiển 3 ô .block_3.

<div class="row">
Năng động
Hoạt động năng nổ
Đam mê
Cháy hết mình
Toả sáng
Giành giải thưởng
</div>
.row {
  /* Mặc định thẻ div hiển thị dọc (block) */
}

Mô Phỏng Hiệu Ứng :hover

Bài tập 2 yêu cầu đổi màu phông chữ khi rê chuột. Thử tương tác với nút bên dưới!

button:hover { background-color: #a855f7; color: white; transform: scale(1.1); }

Cấu Trúc Thẻ Lồng Nhau

Học sinh rất dễ viết sai cấu trúc bao bọc của phần Slogan.

ĐÚNG:
<div class="slogan">
  <div class="row">
    <div class="block_3">...</div>
  </div>
</div>

Nhầm Vị Trí Đặt 'Flex'

Để các ô nằm ngang, display: flex; phải được đặt ở lớp cha (.row), chứ không phải ở lớp con (.block_3).

  • .row chứa display: flex
  • .block_3 chứa width: 33.33%
