Trợ lý học tập ảo (Dựa theo Hình 2.2)

F

Hãy kiểm tra đoạn chương trình sau:

def factorial(n):
    if n = 0:
        return 1
    else:
        return n * factorial(n-1)

Có một lỗi syntax trong chương trình: dòng thứ 2, `if n = 0` cần thay bằng `if n == 0` để kiểm tra bằng với 0, không phải gán giá trị 0 cho `n`.

F

Hãy đưa ra đoạn code đúng.

Dưới đây là đoạn code đã được sửa lỗi cú pháp:

def factorial(n):
    if n == 0:
        return 1
    else:
        return n * factorial(n-1)
