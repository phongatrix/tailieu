Lập trình "theo thủ tục"

  • Phải biết rõ cấu trúc tệp dữ liệu.
  • Phải lập trình lấy đoạn dữ liệu, kiểm tra điều kiện.
  • Mất công sức, dễ nhầm lẫn.
  • Phải viết lại chương trình cho bài toán khác nội dung.

Sử dụng ngôn ngữ SQL

  • Chỉ cần viết yêu cầu dưới dạng câu truy vấn.
  • Chỉ định "muốn làm gì", không phải nghĩ "cách để thực hiện".
  • Mọi việc do hệ QTCSDL giải quyết.
  • Là tiêu chuẩn cho hầu hết hệ QTCSDL (Oracle, MySQL...).

SQL là gì?

Structured Query Language - Ngôn ngữ truy vấn định chuẩn cho việc định nghĩa, cập nhật, truy xuất và điều khiển dữ liệu từ các CSDL quan hệ (từ 1970).

Dễ nhầm lẫn: CHAR vs VARCHAR

CHAR(n): Cố định n kí tự. Dư thì thêm khoảng trắng.

VARCHAR(n): Thay đổi, không vượt n kí tự. Không tự thêm khoảng trống.

Cấu trúc Ngôn ngữ SQL

DDL

Data Definition Language

Ngôn ngữ định nghĩa dữ liệu

CREATE DATABASE Khởi tạo CSDL
CREATE TABLE Khởi tạo bảng
ALTER TABLE Thay đổi bảng
PRIMARY KEY Khoá chính
FOREIGN KEY... Khoá ngoại
DML

Data Manipulation Language

Ngôn ngữ thao tác dữ liệu

SELECT... FROM... Lấy dữ liệu
INSERT INTO... Thêm dữ liệu
UPDATE... SET... Cập nhật
DELETE FROM... Xoá dòng
Các mệnh đề: WHERE, ORDER BY, INNER JOIN
DCL

Data Control Language

Ngôn ngữ kiểm soát dữ liệu

GRANT Cấp quyền
REVOKE Thu hồi quyền
