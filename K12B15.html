Mục Tiêu Bài Học

Sử dụng được CSS màu để thiết lập màu cho chữ và nền của các phần tử trên trang web.

Khái Niệm Quan Trọng

Hệ màu RGB Hệ màu HSL color background-color border Bộ chọn tổ hợp

Nội Dung Dễ Nhầm Lẫn

Tạo màu Xám

RGB: 3 tham số bằng nhau
rgb(128,128,128)
HSL: Độ bão hòa (S) = 0% hsl(0,0%,50%)

Tính Kế Thừa

color, bg-color (Có) border (Không)

Bộ Chọn Con & Anh Em

E F (Mọi cháu chắt)
vs E > F (Chỉ con trực tiếp). E + F (Ngay sát sau)
vs E ~ F (Mọi em phía sau).

Hệ Thống Màu Trong CSS

Tương tác trực tiếp với các thanh trượt bên dưới để mô phỏng cách trộn màu của máy tính!

RGB (Red - Green - Blue)

16,777,216 màu ($2^{24}$)
rgb(128, 0, 128) #800080
Đỏ (R) 128
Lục (G) 0
Lam (B) 128

Ví dụ chuẩn:

  • Trắng: rgb(255, 255, 255)
  • Đen: rgb(0, 0, 0)
  • Xám: rgb(128, 128, 128) (R=G=B)

HSL (Hue - Saturation - Lightness)

Vòng tròn
hsl(300, 100%, 25.1%)
Hue (Tông màu) - 0-360° 300°
Saturation (Độ bão hòa) 100%
Lightness (Độ sáng) 25%

Đặc điểm:

  • H: 0°/360°=Đỏ, 120°=Xanh lá, 240°=Xanh dương.
  • S = 0%: Màu biến mất, thành màu XÁM.
  • L: 0%=Đen, 100%=Trắng, 50%=Màu gốc chuẩn nhất.

Thiết Lập Màu & Tính Kế Thừa

color

Định dạng màu chữ (màu nổi).

Có kế thừa
background-color

Định dạng màu nền của phần tử.

Có kế thừa
border

Định dạng màu khung viền quanh phần tử.

    color: blue;
  }

    color: red;
  }
  em + strong {
    color: green;
  }
  em ~ strong {
    color: purple;
  }
</style>
