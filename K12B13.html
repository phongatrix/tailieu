Bài 13: Khái Niệm, Vai Trò Của CSS

Tin học 12

Mục Tiêu Bài Học

Hiểu được vai trò và ý nghĩa của mẫu định dạng CSS (Cascading Style Sheets) trong việc trình bày trang web.

Khái Niệm CSS

  • Ngôn ngữ mô tả đặc biệt để định dạng trang web.
  • Độc lập: Tách biệt hoàn toàn với mã HTML.
  • Nguyên lý: "Định nghĩa một lần, sử dụng nhiều lần".

Vai Trò & Ý Nghĩa

  • Giải quyết hạn chế làm thủ công của HTML.
  • Tách biệt Nội dung (HTML) và Giao diện (CSS).
  • Giúp web gọn gàng, tải nhanh, khoa học hơn.

Lịch Sử Phát Triển CSS

1994 - Khởi nguồn

Đề xuất bởi Håkon Wium Lie tại CERN (cùng Tim Berners-Lee).

1996 - CSS1

Phiên bản tiêu chuẩn đầu tiên chính thức ra đời.

1998 -> 2011 - CSS2

Khởi động 1998, bản ổn định CSS2.1 công bố 2011.

CSS3, 4, 5...

Phát triển theo từng gói chức năng. Quản lý bởi tổ chức W3C.

Mỗi mẫu CSS gồm 2 phần chính. Trỏ chuột vào mã để xem chi tiết!

1. Bộ chọn
(Selector)

Quy định thẻ HTML nào sẽ được áp dụng (VD: h1, p, h2).

2. Vùng mô tả

Thực Hành Trực Quan

Thay đổi các giá trị ở cột mã CSS bên dưới để xem sự thay đổi trực tiếp lên thẻ HTML bên cạnh.

h1 {
  border: px ;
}

p {
  color: ;
  text-indent: px;
}

Tiêu đề bài viết

Đây là thẻ <p> mô phỏng. CSS giúp định dạng nội dung trang web nhanh hơn, thuận tiện hơn nhờ khả năng "định nghĩa một lần, sử dụng nhiều lần".

Các Loại Bộ Chọn (Selectors) Mở Rộng

Bên cạnh việc dùng tên thẻ (Element), CSS hỗ trợ nhiều cách chọn phần tử rất mạnh mẽ. Hãy nhấp vào từng loại bên dưới để xem cách chúng nhắm mục tiêu chính xác vào các thành phần HTML!

1. Bộ chọn Thẻ (Element Selector)

p { ... }

Nhắm mục tiêu đến tất cả các thẻ có cùng tên (VD: tất cả thẻ <p>).

2. Bộ chọn Lớp (Class Selector)

.highlight { ... }

Nhắm mục tiêu các thẻ có chứa thuộc tính class="highlight". Ký hiệu bằng dấu chấm .

3. Bộ chọn ID (ID Selector)

#main-title { ... }

Nhắm mục tiêu duy nhất một thẻ có id="main-title". Ký hiệu bằng dấu thăng #

4. Bộ chọn Nhóm (Group Selector)

h1, h2 { ... }

Áp dụng chung một định dạng cho nhiều bộ chọn khác nhau. Cách nhau bằng dấu phẩy ,

3 Phương Thức Thiết Lập Định Dạng

CSS Ngoài (External)

Viết trong tệp .css riêng. Kết nối bằng thẻ <link>.

Tối ưu nhất cho nhiều trang web

CSS Trong (Internal)

Viết trong cặp thẻ <style> ở phần <head> của tệp HTML.

Áp dụng cho 1 trang HTML hiện tại

CSS Nội Tuyến (Inline)

Viết trực tiếp vào thẻ HTML thông qua thuộc tính style="...".

Tốn thời gian, nhưng tải ưu tiên nhất
Code View

Nhấp vào một phương thức ở trên để xem cách triển khai mã nguồn
<!-- Trong tệp index.html --> <head> <link rel="stylesheet" href="styles.css"> </head> /* Trong tệp styles.css riêng biệt */ h1 { color: red; }
<!-- Viết trực tiếp trong cặp thẻ head của HTML --> <head> <style> h1 { color: red; } p { text-indent: 15px; } </style> </head>
<!-- Viết trực tiếp vào từng thẻ HTML (Tốn thời gian nếu làm nhiều) --> <body> <h1 style="color: red;">Tiêu đề bài viết</h1> <p style="text-indent: 15px;">Nội dung đoạn văn...</p> </body>
