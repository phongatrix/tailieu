Mô Hình Hộp (Box Model)

Điều Khiển Hộp

box-sizing: border-box

Giữ tổng kích thước không đổi khi thêm viền/đệm.

Trình duyệt giả lập
Tổng Rộng: 290px
Content 
.box {
    width: 150px;
    height: 80px;
    padding: 20px;
    border: 5px solid #854d0e;
    margin: 30px;
    box-sizing: border-box;
}

Các Bộ Chọn CSS Đặc Biệt

.

Lớp (Class)

Gom nhóm nhiều phần tử để định dạng chung. Bắt đầu bằng .

.highlight { color: red; }

Dùng cho: <p class="highlight">

#

Định danh (ID)

Chỉ nhắm vào một phần tử duy nhất. Bắt đầu bằng #

#main-title { font-size: 24px; }

Dùng cho: <h1 id="main-title">

[]

Thuộc tính

Chọn dựa trên thẻ HTML đó có thuộc tính gì. Dùng []

[target="_blank"] { color: blue; }

Dùng cho: <a target="_blank">
